# Assets

Local copies of the locked images from Notion's **Asset Library**. Download each one and save it under exactly this name (JPG is expected; if yours is PNG, change the extension in `elements.yaml` to match).

| Save as | From the Asset Library row | Field |
| --- | --- | --- |
| `characters/aryan/face-closeup.jpg` | Aryan | Face close-up |
| `characters/aryan/sheet.jpg` | Aryan | Reference Image |
| `characters/priya/face-closeup.jpg` | Priya | Face close-up |
| `characters/priya/sheet.jpg` | Priya | Reference Image |
| `characters/auto_driver/face-closeup.jpg` | Auto driver | Face close-up |
| `characters/auto_driver/sheet.jpg` | Auto driver | Reference Image |
| `characters/shopkeeper/face-closeup.jpg` | Shopkeeper | Face close-up |
| `characters/shopkeeper/sheet.jpg` | Shopkeeper | Reference Image |

Only the characters a run actually names need their files present.

Approved start and end frames go in `../frames/<scene>/`, named after the shot (for example `frames/cold_open/CO-01.png`).
