# Set up a Physics scene

Use the [Shot Production Playbook](https://app.notion.com/p/400252f6b4ff81c0be66c3c487b394e6), especially stages 1–5, and the repository's [AGENTS.md](../../../AGENTS.md). Keep current plans, media selections and review notes on the existing scene row in [Film Structure — Scenes](https://app.notion.com/p/860e5425a76c43d08cd09837ac1f5272). The repo commands build local media under `out/`. For exact fields, commands and revision checks, read [the scene handoff reference](references/scene-handoff.md) as needed.

## Start or resume

1. Resolve the scene number or name to its existing row. Read its Stage, Open Calls, current plans, media and review notes. Compare local renders with the identified Notion attachments when the difference matters. Stage labels and file presence are clues. Use recorded review decisions and the actual inputs to determine readiness.
2. Locate the approved screenplay scene and adjoining moments. For new writing or performance, read the original story context, the relevant full Character Bible entries and the World Bible or locked assets. Resolve material conflicts with Vineet before writing dependent requests. Reuse approved work that still matches.
3. Identify the first missing decision or stale dependency. Continue from there and group related review items. If the user asks only for a status check or a plan, report the first actionable step without making production changes.

## Work through the stages

| Stage | Work and handoff |
| --- | --- |
| **1. Screenplay** | Establish what happens and what is heard, with exact Hindi/Hinglish lines, visible and off-screen actions, overlaps, meaningful pauses and the scene's turn. Check what each character knows and how the scene joins its neighbours. Vineet approves changes before they enter the screenplay. |
| **2. Exposure, performance and Sound script** | Give each story beat its action, camera intention and sound lanes. Sketch provisional timing and distinguish timing sounds, follow-picture sounds, beds, silence and motif marks. Record each relevant character's opening state, beat-by-beat changes and closing state. Write the scene's Sound script from the approved words and arc, with restrained delivery tags and a list of required sounds. Mark absent voices or lanes as inapplicable. |
| **3. Voices, sounds and radio cut** | Reuse approved audio and locked voices/motifs. Preview actual missing requests and cost before any paid generation. Vineet listens to takes before selecting them. Put approved line files, effects and beds on the scene's Radio cut plan. Render and apply [radio-cut-review](../radio-cut-review/SKILL.md). After listening approval, save the radio cut and carry its measured cues into the exposure sheet. |
| **4. Storyboard** | Use the approved exposure, radio timing and performance arc to plan frozen moments that make staging, action, geography and reactions readable. Reuse views when they still work. Save prompts and reference roles on the scene page for Vineet's Gemini work. Apply [storyboard-review](../storyboard-review/SKILL.md) to actual panels and save the approved files. |
| **5. Animatic** | Write the Animatic plan against the approved radio and panel filenames, with holds, pushes and transitions where useful. Render picture and sound together, apply [animatic-review](../animatic-review/SKILL.md) and have Vineet watch the actual render. Save the approved animatic on the scene row. |

A beat can share a panel with another beat. The animatic tests scene rhythm and staging. Use the approved radio and measured cue list for timing, the storyboard for staging, and the performance arc for intent. The radio cut continues through production and editing. When an approved input changes, rebuild and review affected outputs, including shot timings and assembly where relevant.

## Leave the scene ready for the next thread

Record the current decision, exact approved or pending artifacts, any relevant local path, and the next action on the scene row using its existing fields and notes. Include evidence limits when playback was unavailable. When the animatic is approved, report **ready for Animation** and identify the radio cut and animatic to use when defining the working shots. End this skill's work at that handoff.
